# DB Temperature / Prestress

> Source: MIDAS API Online Manual  
> Official manual: https://support.midasuser.com/hc/en-us/articles/33016922742937-MIDAS-API-Online-Manual  
> Mirror/index: https://github.com/Dennis5882/MIDAS-API/tree/main/docs/manual

## Scope

本章单独对应 MIDAS API 的一个二级功能章节。接口保持“**二级页面 → Registry → 4 个 MCP Tool**”映射，不把每个 MIDAS endpoint 暴露成独立 MCP Tool。

### Base URL

```text
https://moa-engineers.midasit.com:443/gen
https://moa-engineers.midasit.com:443/civil
```

### HTTP Headers

```http
Content-Type: application/json
MAPI-Key: <MAPI_KEY>
```


## Endpoint Registry

| Endpoint | URI / Methods | 功能 | Request wrapper |
|---|---|---|---|
| `ETMP` | `CRUD /db/ETMP` | Element temperature | `Assign` |
| `GTMP` | `CRUD /db/GTMP` | Temperature gradient | `Assign` |
| `BTMP` | `CRUD /db/BTMP` | Beam section temperature | `Assign` |
| `STMP` | `CRUD /db/STMP` | System temperature | `Assign` |
| `NTMP` | `CRUD /db/NTMP` | Nodal temperature | `Assign` |
| `TDNT` | `CRUD /db/TDNT` | Tendon property | `Assign` |
| `TDNA` | `CRUD /db/TDNA` | Tendon profile | `Assign` |
| `TDCS` | `CRUD /db/TDCS` | Tendon composite-section location | `Assign` |
| `TDPL` | `CRUD /db/TDPL` | Tendon prestress | `Assign` |
| `PRST` | `CRUD /db/PRST` | Prestress beam loads | `Assign` |
| `PTNS` | `CRUD /db/PTNS` | Pretension loads | `Assign` |
| `EXLD` | `CRUD /db/EXLD` | External pretension load case | `Assign` |

## MCP 映射规则

```text
GET     -> midas_db_query
POST    -> midas_db_assign
PUT     -> midas_db_assign
DELETE  -> midas_db_delete

DOC command -> midas_doc
```

## Registry / validation notes

1. endpoint key 必须来自 Registry，不接受任意 URL。
2. `Assign` 与 `Argument` 必须由 Registry 决定，LLM 不直接决定 wrapper。
3. POST/TABLE 以 `TABLE_TYPE` 区分逻辑端点。
4. POST/TEXT 以 `TEXT_TYPE` 区分逻辑端点。
5. DELETE 必须有明确目标 ID。
6. 长耗时 ANAL 必须使用独立 timeout / project lock。
